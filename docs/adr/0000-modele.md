# ADR-0000 — Modèle

- **Statut** : proposé | accepté | remplacé par ADR-XXXX
- **Date** : AAAA-MM-JJ
- **Contexte** : le problème, les contraintes, les chiffres qui comptent.
- **Options considérées** : au moins deux, avec pour / contre.
- **Décision** : une phrase.
- **Conséquences** : ce que cela impose, ce que cela interdit, comment on le vérifie.
- **Dérogation RAIDER** (si applicable) : principe concerné et justification.
